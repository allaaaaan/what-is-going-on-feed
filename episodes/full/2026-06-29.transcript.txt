大家好,这里是又咋啦?!完整版。今天是2026年6月29日,为你带来今天所有值得关注的科技动态。

首先来看 AI / 大模型。

第一,AMD Strix Halo RDMA 集群配置指南最近在 GitHub 上引发了关注,标志着本地 AI 计算的一个真实里程碑。Strix Halo 是 AMD 的一款芯片,搭载一百二十八G统一内存,在小型主机上售价约为两千美元。通过 RDMA——一种让两台机器通过高速网络直接共享内存的技术——双节点集群可以合并到两百五十六G,足以在没有任何云端基础设施的情况下跑起七百亿参数的大模型。作为对比,一张 NVIDIA H100 GPU 单卡售价超过三万美元。能跑起来的本地 AI 推理,门槛正在从企业级硬件预算降到高配笔记本的价位。硬件价格还在往相反方向涨,但这个能力门槛的跨越是真实的。

第二,OpenAI 的 AI 编程助手 Codex 有一个长期未解决的 GitHub issue：没有机制能把敏感文件排除在 agent 的访问范围之外。关键不只是 agent 主动读取文件——当它执行 grep 或 ripgrep 等命令时,工作区里任何包含搜索关键词的文件内容都会出现在工具输出里,然后发给模型。API 密钥、访问凭证、私有配置,全都可能被意外触及。唯一可靠的方案是在会话开始前做容器隔离或 Unix 文件权限设置。如果你在含有任何敏感信息的工作区里跑 AI 编程 agent,容器隔离应该是默认选项,而不是可选项。

第三,一位开发者分享了他用 Claude Code 分析自己 MRI 片子的经历——在医生建议手术之前,他用 AI 做了一次独立的二次诊断。AI 将书面治疗方案与最新临床指南交叉对比,发现了一处不一致：推荐的处理方式与该类诊断最新循证指南相矛盾。AI 并没有重新解读影像,也不是在取代放射科医生,它做的是把治疗计划与已发表证据做交叉比对,而这个速度和广度是普通患者自己无法做到的。这背后的信息不对称是真实的：患者面对专科会诊时掌握的信息量远低于医生,AI 二次意见正在改变这个斜率。反面的风险也是真实的：一次有用的判断,并不能告诉我们同一个模型在相邻场景里犯了多少错,而那些错误我们往往听不到。

第四,本周流传的一篇文章指出,软件工程正在经历结构性的身份转变。AI 出现之前,写代码本身是耗时的技能型工作——把"产品应该做什么"映射成"能运行的实现",是工程师大部分时间的所在。这个步骤正在被自动化。有人描述：一个单人项目,现在一周就能完成,同样的工作在2019年需要一个月。另一位观察者直接指出：在需求已经定义完成后才进入项目的工程师,作为一个类别,已经基本被淘汰了。留下来的、还没被自动化的,是上游的工作：定义要做什么、框定需求、决定代码将在哪些抽象层次里生存。实现阶段在边界情况和系统集成上仍然需要判断力——但价值重心正在从"怎么做"转向"做什么"。在这个时代能留下来的工程师,是那些掌握上游定义权的人。

第五,Google 遭遇了 Gemini 模型的产能瓶颈,正在限制 Meta 的使用量。新闻背后是一个供给问题,不是政策限制——Google 目前的推理基础设施已经无法覆盖当前需求。即便在超大规模云厂商这个层面,前沿模型的 GPU 算力依然是真实紧缺的。

第六,有一种企业 AI 推广策略叫 Tokenmaxxing——用员工的 AI token 消耗量来衡量 AI 采用率,强制大量使用——正在被当初推行它的公司悄悄放弃。这个策略并非没有道理：强制高频使用让员工发现了 AI 在哪些工作流里真正能省时间。但用 token 花费衡量绩效从来只是一个过渡机制,不是可持续的指标。公司现在正在重新校准到 AI 带来的产出,而不是在它上面的花费。结论是：企业 AI 采用的"强制参与、再提炼洞察"阶段已经完成使命,跑过这个阶段的公司正在进入更精准的下一步。

第七,IBM 研究人员发表了一篇论文,介绍了一台拥有一百万个 p-bit 的可编程概率计算机。p-bit 即概率比特,可以同时表示一定范围内的值,而不是传统的二进制零或一。目标工作负载是优化问题和玻尔兹曼机风格的神经网络——在这类任务中,训练时的随机性本身是有益的。p-bit 硬件把这种随机性直接实现在芯片上,而不是在确定性 GPU 上模拟。这还是硬件研究,不是短期内的产品方向——但它属于一个更大趋势的一部分：寻找能让 AI 训练天然依赖的随机运算变得更廉价的架构。

接下来是 privacy / 隐私监控。

第一,欧盟正在以闭门谈判的方式推进《聊天控制》立法,绕过了欧洲议会正常的审查程序。《聊天控制》要求消息平台扫描所有私人数字通讯内容,检测儿童性虐待材料和恐怖主义内容。这在技术层面意味着什么：它要求从根本上打破端对端加密。目前提供端对端加密的应用——Signal、WhatsApp、iMessage——要么在加密前添加客户端扫描,要么放弃端对端加密、退出欧盟市场,二选一。从地缘政治角度看,欧盟在通讯监控这件事上,正在向中国的监控模式靠拢,而不是远离它。保护儿童、防止恐怖主义的目标是真实的；但这套机制一旦建立,在技术层面没有任何东西能阻止它被用于其他目的。

第二,一份对比公共 DNS 解析服务的指南近日引发讨论,因为它明确记录了一个细节：每一项具有中国运营关联的 DNS 服务,都注明"依照中国法规运营"。在2026年,这个细节对中国之外的用户同样日益相关,数据管辖权的担忧已经蔓延至更大范围。DNS 是每一次互联网连接的第一步——选择解析服务商,也是在选择你的上网元数据流经哪个监管环境。

第三,加利福尼亚州同意将全部驾照记录上传至联邦全国数据库,依从了2005年《Real ID 法案》——美国国土安全部以"拒绝配合则加州身份证件将无法在机场使用"相威胁。实际效果是：此前分散在五十个州级数据库中的驾驶证信息,被整合进了一个联邦可访问的中央库。这次配合是在数百万加州居民面临出行中断威胁下被迫发生的。

接下来是 industry / 行业。

第一,密歇根州提出了《工作场所边界法案》,旨在禁止雇主要求员工在合同约定工作时间以外回复通讯。法国、葡萄牙和欧盟多个国家已有类似保护。密歇根州如果通过,将成为美国率先以法律形式确立"断线权"的少数几个州之一。

第二,MUMPS——一门设计于1966年的编程语言——至今仍然驱动着 Epic Systems,美国最大的电子病历系统,覆盖全美约百分之三十五的医院。本周出版了原版 MUMPS 入门书的周年纪念版。评论区的总结是：美国现代医疗 IT 最核心的基础设施,跑在一套比互联网、比个人电脑、比许多使用它的医生都还要老的技术上。年代久远和已经过时,不是一回事。

第三,《大西洋月刊》刊发了一篇波音747退役长文。终结它的经济逻辑很简单：777 和 787 的座舱宽度与747相当,每座位油耗却低百分之三十,而且只有两台发动机而不是四台。747 标志性的上层甲板并不是为乘客而设计的——它是波音在一场最终输给 C-5 Galaxy 的军用运输机竞标中留下的结构痕迹。市场走向了效率,747 没有。
