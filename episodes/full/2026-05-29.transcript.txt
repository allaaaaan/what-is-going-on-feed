大家好,这里是又咋啦?!完整版。今天是2026年5月29日,为你带来今天所有值得关注的科技动态。

首先来看 AI 与大模型。

第一,最近 TechCrunch 有一篇文章引发广泛讨论——科技圈的 CEO 们似乎正在集体经历某种 AI 焦虑症。现象是这样的:董事会、投资人和竞争对手都在要求「立刻上 AI」,但没有人认真问过「上什么 AI 能解决什么具体问题」。结果不少 CEO 开始强迫自己相信,那些目前还不成立的 AI 应用场景已经触手可及。这里有一个值得警惕的陷阱:当「AI 转型」变成了 KPI 而不是真正的业务目标时,公司往往会先投入资源、后倒推理由。从公开信息推断,这种压力来自多个方向——资本市场奖励「AI 原生」公司更高的估值溢价,人才市场里 AI 相关招聘成了竞争焦点,媒体则把「用 AI 提效」当作正确答案不断强化。真正的问题不在于是否相信 AI,而在于一家公司是否有能力先搞清楚自己的工作流程,再谈用什么工具改造它。

第二,有一个能回答「AI 公司有没有真正的用户价值」的市场信号刚刚变得非常清晰:Anthropic 和 OpenAI 都在大幅提高 API 定价,背后的逻辑是两家公司在企业级编程 Agent 这个方向上,已经找到了真正的产品市场契合点。以前大部分 AI 用户每月付十几美元买一个消费级订阅;现在企业客户为这类 Agent 产品每人每月愿意付两百美元甚至更多。两百美元对于一家公司是很小的成本,但乘以几万名员工,规模就完全不同了——这才是两家公司能把 API 价格定得更高的底气。

第三,AI 编程 Agent 公司 Cognition——也就是 Devin 背后的团队——最新一轮融资超过十亿美元,估值达到二百六十亿美元。Devin 已经在帮 Mercedes-Benz 和巴西大型银行 Itaú 处理实际工程任务,显著压缩了项目周期。高估值反映的是市场对「AI 软件工程师」这个品类的强烈预期。

第四,OpenAI 用 Codex 给一家叫 Thrive Holdings 的公司构建了一个能自我改进的税务准备 Agent。它在生产环境中发现自己的错误并自动修正,而不是等人工反馈周期转一圈再改。这是 AI Agent 在垂直专业领域真正落地的一个值得记录的案例——处理越来越复杂的税务申报,同时持续学习。

第五,ElevenLabs 发布了 Music v2,一个可以在播放过程中实时切换风格和流派的音乐生成模型,同时保持人声和编曲的连贯性。AI 音乐生成正在从「生成一首歌」进化成「动态编排」能力,对广告、游戏、播客背景音乐等场景的影响会比较直接。

第六,Anthropic 宣布计划将 Claude 的语音交互模式扩展到新增十八种语言,让更多语言的用户能够以对话方式使用 Claude。

第七,Google 在企业版 Gemini 中新增了可共享的 Projects 功能,允许团队成员在同一个多界面工作空间内协作。这类似于把 Notion 或 Slack 的团队共享空间概念直接集成进 AI 工作流。

第八,这一条是偏技术的,但值得提一下它的工程意义:Delta Weight Sync 是一种在分布式 AI 训练中只传输「变化部分」参数的方法,将节点间通信量从 GB 级压缩到 MB 级。分布式训练的瓶颈往往不是算力而是节点间通信成本,如果这类技术被广泛采用,意味着未来大规模模型训练可以在更分散、更低带宽的基础设施上进行,而不必依赖超高速互连。

第九,CZ Biohub 发布了一套开放的蛋白质结构预测和设计工具,包括语言模型 ESMC、三维结构设计引擎 ESMFold2,以及可检索六十八亿条蛋白质序列的 ESM Atlas。这三个工具对全球研究人员免费开放。生物学领域的 AI 基础设施正在以和软件领域类似的节奏开放化。

接下来是行业动态。

第一,Nvidia 宣布每年投入一千五百亿美元,持续深化与台湾的合作关系,并在台湾新设总部,扩大与台积电的战略伙伴关系。背景是此前有声音说 Nvidia 可能跟随美国政策向本土制造转移;但现实是台湾在先进封装技术方面的优势在美国还没有对应的基础设施。Nvidia 的选择传递了一个清晰的信号:供应链决策优先于地缘政治姿态。

第二,在 Google 大力推广其 AI Overview 功能之后,DuckDuckGo 的搜索流量在一周内暴增百分之二十八。AI Overview 是 Google 在搜索结果顶部用 AI 直接给出答案的功能。这个数字说明,相当数量的用户在「Google 搜索变成了 AI 回答」这件事上选择了用脚投票。

第三,YouTube 宣布将自动为包含大量写实 AI 生成内容的视频添加标签,不再完全依赖创作者自行申报。随着视频合成质量的提升,平台方主动介入标注已经成为必要。

第四,音乐数据平台 Last.fm 成立于二零零二年,最近从此前的母公司获得独立,成为自主运营的公司。Last.fm 是少数历经二十多年依然活跃的互联网老字号,独立后能否重新获得增长动力值得观察。

第五,Valve 宣布全线上调 Steam Deck 价格,其中一 TB 版本涨价三百美元,新售价为九百四十九美元。这次涨价幅度不小,官方没有给出明确原因,市场普遍判断与供应链和关税压力有关。

第六,加拿大政府宣布将向瑞典萨博公司订购一批军用侦察机,而非继续依赖美国供应商。这是加拿大在军事采购上对美国供应链依赖的明显转向。对科技行业来说这个信号值得关注:当盟友关系也不足以保障供应链稳定时,欧洲供应商的战略地位正在上升。

第七,一名 Google 员工因利用公司非公开的搜索数据,在预测市场平台 Polymarket 上提前押注并获利,被以欺诈和洗钱罪起诉。Polymarket 是一个让用户用真实资金对未来事件结果下注的平台。这个案子说明,预测市场在监管层面的模糊地带正在被具体案件填充。

接下来是 AI 工具与开发者生态。

第一,OpenAI 发布了 Secure MCP Tunnel,让企业可以把私有服务器接入 OpenAI 的产品,同时不需要把服务器暴露到公网。MCP 是 Model Context Protocol 的缩写,也就是让 AI 访问外部工具和数据的标准协议。这个工具主要解决的是企业合规问题:既想让 AI 能访问内部数据,又不想把内部系统开口对外。

第二,GitHub 经历了一次影响广泛的服务中断,波及 Pull Request、Issue、Git 操作和 API 请求。对于把 GitHub 作为唯一协作和持续集成入口的团队来说,这类事件是一次提醒:单点依赖的风险是真实存在的。

第三,Cloudflare 发布了新的开发者平台 Flagship,提供了一套在其全球网络上的零跳延迟功能抽象层。Cloudflare 一贯擅长在其全球网络上为开发者提供低配置、高性能的工具层,Flagship 是这个方向的最新一步。

第四,Apex 是一个专门为 React Native 开发训练的编程模型,针对这个框架的架构决策和常见问题进行了优化。它在通用编程基准测试上不如顶级大模型,但在 React Native 这个具体场景中大幅改善了性价比。目前处于私测阶段。

第五,NVIDIA 发布了 LocateAnything,一个视觉语言定位框架,可以并行解码图像中目标物体的边框,而不是逐 token 一个个输出,显著提升了目标定位的处理速度。

第六,产品分析工具 PostHog 公开记录了他们训练自有 AI 模型的过程,其中一个细节在社区引发了讨论:他们在用用户数据训练模型时,采用了「默认选择参与」的机制。有评论指出,「默认选择参与」本质上等于没有真正赋予用户选择权——这是 AI 数据治理领域一个正在被反复讨论的设计取向问题。

接下来是太空与机器人领域。

第一,关于 SpaceX 的估值,市场上流传的数字是二万亿美元。这个估值建立在一系列工程假设的叠加上:Starship 必须如期完成规模化运营,AI 推理需求的增长还需要继续指数级放大,轨道数据中心这个概念需要真正商业化落地。从公开信息合理推断,目前的高估值更多反映的是成功路径的故事吸引力,而不是已实现的基本面。Elon Musk 已经在多个赛道推动了真实的工程进展,这不是空洞的故事;但把所有假设的成功概率链条叠加起来,置信区间会非常宽。

第二,SpaceX 赢得了美国太空军价值二十九亿美元的固定价格合同,用于构建一套基于 Starlink 技术的天基感知与打击指引网络。这个系统将成为美国太空军战斗系统的核心通信层,连接传感器与打击终端。SpaceX 须在二零二七年底前交付完整原型。

第三,Tesla 宣布位于得克萨斯 Gigafactory 的 Optimus 机器人专属工厂正式开工建设,新增厂区面积约四十八万平方米。计划日产量约两万七千台,预计今年七到八月开始小批量生产,二零二七年夏进入高产量阶段。如果产能目标兑现,这将是迄今为止规模最大的人形机器人工厂。

接下来是消费者科技动态。

第一,Apple 和 Google 已经开始在用户看到通知之前,用设备端 AI 模型对通知进行解析、排序、摘要和重写。更进一步的方向是:通知正在从「给人看的信息」演化为「给 Agent 消费的触发器」。对于开发者来说,这意味着通知的原始文本格式将直接影响 AI 对它的处理方式——这是在产品设计层面需要开始考虑的变化。

第二,Apple 正在为 iPhone 开发一个防抢功能:一旦系统通过陀螺仪、加速度计等传感器检测到手机被猛然夺走,设备会立即锁定。Android 已经有类似功能。这个功能目前尚未有明确发布时间表。

第三,今天最后一条来自 TLDR 的一篇分析文章,核心观点值得记录:即便大型 AI 实验室最终实现了「自动化所有软件工作」,也不意味着垂直行业的机会消失。相反,模型之外的系统工程——如何让 AI 输出在特定行业里可信、合规、可操作——才是真正的壁垒所在。这与我们前面提到的 Thrive Holdings 税务 Agent 案例是同一个逻辑:水平工具降低了 AI 的准入门槛,但垂直场景的专业判断仍然需要人类专业知识的介入和背书。
