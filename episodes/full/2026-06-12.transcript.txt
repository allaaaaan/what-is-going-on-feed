大家好,这里是又咋啦?!完整版。今天是2026年6月12日,为你带来今天所有值得关注的科技动态。

首先来看 AI / 大模型。

第一,OpenAI 正在考虑大幅下调 API 定价,原因是预判 Anthropic 也会跟进降价。两家公司目前都在为算力成本烧掉数十亿美元,一旦开打价格战,将是各自商业模式在上市前最直接的一次压力测试。

第二,Google 发布了 DiffusionGemma——一个拥有两百六十亿参数的混合专家模型。它采用文本扩散的方式,每次同时生成一整段文字,而不是逐词输出,在 GPU 上的生成速度最高可达传统模型的四倍。量化后可以在消费级高端显卡上运行,对延迟敏感的应用场景非常有吸引力。

第三,Anthropic 推出了 Claude Managed Agents,一套面向生产环境的智能体编排 API。开发者不再需要自己拼接基础设施,而是直接获得一个集成好的调度层,让搭建可靠智能体系统的门槛大幅降低。

第四,Anthropic Fable 5 模型的系统提示词遭到泄露,内容长达约十二万字。这是业界罕见的一次对顶级 AI 模型内部指令的直接披露,对研究 AI 行为边界或关注 AI 安全的人来说都有参考价值。

第五,Cursor 的 AI 代码审查工具 BugBot 迎来重大更新:运行速度提升超过三倍,成本下降百分之二十二,发现 bug 的数量增加百分之十,大多数审查在三分钟内完成。对于依赖 AI 辅助代码审查的团队,整个反馈循环明显缩短了。

第六,Stack Overflow 发布了面向 AI 智能体的 API 优先知识平台。它使用多智能体验证循环来生成经过现实检验的标准化答案,供智能体以机器速度消费,弥合了静态训练数据与快速变化的生产实际之间的鸿沟。

第七,Apache Burr 是一个新的开源智能体框架,内置状态管理、重试逻辑和可观测性支持,专门解决从实验性演示到生产级部署之间的工程落差。

第八,来自 Anthropic 红队的研究表明,语言模型可以在不生成任何输出的情况下完成分类任务——方法是提取最后一个提示词位置的隐藏状态,通过一个极小的探针网络直接输出结论。这意味着分类场景的推理成本可以比完整生成低得多。它是一个早期信号,提示 AI 部署的经济学正在向很多团队尚未预判的方向演变。

第九,本周一篇被广泛讨论的文章指出,AI 产品真正的竞争壁垒不来自于使用前沿模型——这些模型随时可能被限制、涨价或收回——而在于掌控完整的反馈闭环:模型选择、微调、评估和工作流整合。依赖外部能力、自己不构建闭环的公司,正在借来的地基上盖楼。

接下来是 AI 产业 / 策略。

第一,Anthropic CEO Dario Amodei 只有一名直接下属——他的首席幕僚。公司所有执行团队都向 President Daniela Amodei 汇报,由她负责日常运营。这种领导结构在科技行业极为罕见。有意思的是,这或许正是一家以安全为使命的实验室在快速扩张中保持研究专注的方式——值得思考这种安排背后的信号。

第二,Dario 发表了一篇关于 AI 政策的长文,提倡建立类似美国 FAA 的监管框架:强制部署前测试、更严格的安全标准,以及各国政府在高风险模型上的协调机制。文章还涉及 AI 驱动的就业冲击和宏观经济应对。这是迄今为止来自顶级实验室 CEO 最系统的监管提案。

第三,Palantir CEO Alex Karp 表示企业客户对前沿 AI 实验室越来越不满意。他的说法是:这些实验室把 token 消耗量当作生产力的代理指标来优化,与企业追求的实际 ROI 之间存在明显落差。成本上涨的速度快过业务价值的产生,这个缺口正在开始显现。

第四,欧盟裁定 Meta 违反了数字市场规则,命令其开放 WhatsApp Business API,允许竞争对手的 AI 聊天机器人免费接入。Meta 计划上诉,称此举是监管过度。对于在消息平台上构建业务的开发者和企业来说,这是一个实质性的新开口。

第五,OpenAI 正在租用一个俄亥俄州的数据中心园区,总用电规模达一百亿瓦,预计2028年投入使用,合同为期二十年,由 NVIDIA 提供背书。一百亿瓦大约相当于十座大型核电站的总产出。这是 AI 算力军备竞赛最直观的一个注脚。

第六,AWS Bedrock 宣布新增数据共享要求:客户在使用 Anthropic Mythos 模型及未来前沿模型时,需要同意与 Anthropic 共享数据。这引发了强烈反弹——Bedrock 最初的价值定位是供应商中立的模型访问层,而现在它实际上已经成为 Anthropic 的一级发行渠道,功能还比直接调用 Anthropic API 少。一篇广为流传的分析文章直白地写道:AWS 亲手摧毁了 Bedrock 的价值主张。

第七,Meta 正在使用临时帐篷结构快速搭建 AI 数据中心,绕过永久建筑漫长的审批流程。背后的逻辑是:现在的部署速度比设施的永久性更重要。这个细节清楚地说明了 Meta 在 AI 算力竞赛中追赶对手的紧迫感。

第八,特朗普计划近期召集约十二到十五名 AI 领域顶级高管开会,讨论科技公司向公众回馈利益的方式,可能包括向公众分配 AI 企业的股权。具体机制尚不明朗,但 AI 财富集中的问题正在以这种方式被推上最高政治议程。

第九,AI 正在加速安全漏洞的利用速度。研究发现,针对 N-day 漏洞——即已公开披露但尚未在所有设备上完成修复的漏洞——AI 可以自动化大量逆向工程工作,将漏洞被利用的窗口期大幅缩短。过去依赖"补丁公开到被攻击有时间差"作为安全缓冲的假设,现在需要重新审视。

第十,一位安全研究员演示了一种攻击方式:通过向 AI 银行智能体发起一笔一分钱的转账,在备注字段植入自然语言指令,触发 LLM 执行未授权操作。这是一个生动的例子:能够执行金融操作的智能体系统,和只回答问题的聊天机器人在安全性质上有本质区别。

第十一,越来越多企业正在将工作讨论的录制设为默认开启,以便将内容输入 AI 会议总结和生产力工具。这种转变往往没有经过明确的知情同意流程。对员工来说,这意味着工作的感受正在悄然改变;对企业来说,这是一个 AI 效率收益能否值回文化成本的赌注。

第十二,一篇写于1989年的论文正在重新引发关注。它研究的是电气化时代的生产率悖论:电力普及了数十年,却迟迟没有反映在生产率统计数据上——因为企业必须彻底重组工作流程、管理结构和技能体系,收益才会真正显现。AI 时代的类比不言而喻。那些用 token 消耗量或任务完成数来衡量 AI 价值的公司,或许问错了问题。

接下来是 资本市场 / 行业动态。

第一,SpaceX IPO 今日定价,每股一百三十五美元,共发行五亿五千五百六十万股,认购超过发行量四倍以上。若上市后维持需求,这将成为史上规模最大的 IPO。股票将在纳斯达克以 SPCX 为代码交易。

第二,OpenAI 已向美国 SEC 提交保密 S-1 文件,为今年晚些时候上市保留选项,同时筹备员工流动性计划,对应估值约八千五百二十亿美元。Anthropic 此前也已提交保密上市申请。加上 SpaceX,科技行业可能正迎来近年来最密集的顶级 IPO 窗口。

第三,意大利软件并购公司 Bending Spoons 已向美国 SEC 提交上市申请,目标估值二百亿到二百二十亿美元。这是一个不寻常的 IPO 故事——一家盈利稳定的并购型公司,而非烧钱换增长的风险投资型企业。

第四,Visa 与 OpenAI 宣布合作:Visa 的支付网络、身份认证和安全基础设施将直接集成进 ChatGPT,让 AI 智能体能够代表用户发起并完成支付。这是首个大规模落地的主要支付卡网络与 AI 模型的直接整合。

第五,Mastercard 推出了 Agent Pay for Machines,专门设计用于 AI 智能体之间高频、连续、往往是亚分钱级别的交易结算。首批超过三十家合作伙伴涵盖 Coinbase、Stripe、Cloudflare、Polygon、Solana Foundation 和 Tempo。系统支持智能体身份认证、程序化授权和跨渠道结算。

第六,布鲁克林联邦法院初步批准了 Visa、Mastercard 与约一千二百万商户之间的三百八十亿美元和解协议,终结了一场始于2005年的刷卡费诉讼。根据协议,两大网络将在五年内降低零点一个百分点的交换费,并在八年内将标准消费者卡费率封顶在百分之一点二五。更重要的是,"荣誉所有卡"规则被削弱——商户现在可以拒绝整个卡级别,而不必无条件接受网络内的每一种卡。

第七,JPMorgan Chase 部署了 AI 和机器人来自动化纸质支票处理——机器人负责拆信封、取出文件、移除订书钉并扫描,AI 负责数据提取。系统每年处理四亿八千万张支票,准确率超过百分之九十九点九。这提醒我们,AI 在金融领域近期最大的生产力影响,可能来自于最平凡、最依赖纸张的后台操作。

第八,印度最大支付平台 PhonePe 推出了 SmartPages——一个 AI 驱动的支付页面自动生成工具,直接内置于支付网关后台。对于没有工程资源的中小商户,这大幅降低了上线在线收款的门槛。

第九,一个由 AI 和金融领导者组成的小组指出:在 AI 时代脱颖而出的财务团队,不仅在使用 AI 工具,而且正在成为构建者——他们用 Claude Code 和 MCP 自己搭建自动化流程。不能跨越这条线的财务人员,有被工具管理而非管理工具的风险。

第十,本周一篇文章作了一个值得记住的区分:拥有支付策略,和拥有供应商选择,是两件不同的事。许多公司在没有明确战略之前就锁定了底层架构,等到发现错位时,代价已经折算成了工程迁移成本、客户流失风险和数月的收入损失。这个教训同样适用于任何在产品策略确定前就做出的基础设施决策。

接下来是 科技前沿 / 工具。

第一,美国生物技术公司 Life Biosciences 完成了首批患者用药,注射一种实验性基因疗法,目标是逆转与年龄相关的视力衰退。该疗法通过单次注射激活视网膜神经中的三个再生基因,研究将跟踪参与者至少五年。这是针对视力的细胞重编程疗法首次进入人体试验。

第二,中国国家药监局批准了 NeuraMatrix 与清华大学联合研发的 NEO 脑机接口商业化上市——一枚硬币大小的设备,贴附在大脑表面,让患者用意念控制气动手套。相比之下,Neuralink 在美国仍处于研究协议阶段,距离 FDA 商业许可还有数年距离。在脑机接口商业化这件事上,中国已经领先了。

第三,特斯拉 Robotaxi 服务在德克萨斯州三座城市运营了五十九辆车。早期乘客反映等待时间长、行程途中频繁停顿。以目前规模来看,这更接近一个试点而非成熟产品——而自动驾驶收入一直是特斯拉估值故事的核心,这让相关时间表的可信度打了折扣。

第四,Google Chrome 将永久终止对 Manifest V2 浏览器扩展的支持,这直接终结了 uBlock Origin 等广告拦截器的所有可用变通方案。Microsoft Edge 和 Opera 将跟进。对于依赖广告拦截来保护隐私和提升浏览速度的用户来说,这是一次实质性的功能降级——浏览器厂商的利益归根结底与广告驱动的商业模式绑定在一起。

第五,Apple 发布了 macOS Container Machines,在 Apple Silicon 上原生支持 OCI 容器,无需 Docker Desktop 或虚拟化方案,直接提供持久化、文件系统共享的 Linux 容器。对于在 Mac 上构建或测试 Linux 工作负载的开发者,这是一次显著的体验改善。

第六,梅赛德斯-奔驰在收购英国 Yasa 公司后,已开始大规模量产轴向磁通电机。轴向磁通电机在相同功率输出下,体积和重量远小于传统径向磁通设计,奔驰押注这一技术将成为其下一代电动车阵容的差异化竞争优势。

第七,Papers with Code——这个将机器学习研究论文与代码实现挂钩的平台——在沉寂一段时间后重新上线。对于需要复现研究结果或基于已发表成果继续工作的研究人员和从业者来说,这是一个有用的基础设施恢复。

第八,新的 Postgres 兼容连接池和分布式查询路由器 PgDog 宣布完成融资并正式上线。它通过智能路由将查询分发到读副本和写节点,专门应对 Postgres 的扩展瓶颈。对于单节点 Postgres 已达上限的团队,值得评估。

第九,GitHub 发生了一次认证中断事故,导致 API 请求全面失效,用户无法通过 Pull Requests 扩展及相关工具进行认证。事故已解决,但这是一个提醒:现代开发工作流与 GitHub 作为单一依赖点的耦合有多紧密。

第十,NASA 喷气推进实验室的工程师介绍了他们如何让已在火星运行十三年的好奇号探测器保持运转:精细的电源管理、上传数月后才执行的软件更新,以及一支在超过十年的工作中几乎背熟了这台机器所有怪癖的团队。这是一个在完全无法进行实物接触的条件下,维护复杂系统的罕见工程案例。

第十一,HelixDB 是一个新的开源图数据库,专为 AI 智能体的上下文存储和知识图谱构建设计。它将向量搜索和图遍历结合在一起,面向需要在多步推理中保留结构化关系的应用场景。
