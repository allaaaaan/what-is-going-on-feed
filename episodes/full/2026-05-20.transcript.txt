「又咋啦?!」2026年5月20日，全集。

【AI公司格局】

Andrej Karpathy 加入了 Anthropic。Karpathy 是 OpenAI 初创团队成员，后在 Tesla 担任 AI 总监多年，主导了 Autopilot 的神经网络架构，同时做了广为人知的神经网络开源教程项目。他上次离开 OpenAI 后一度专注于独立教育项目，这次选择加入 Anthropic 而非重返 OpenAI 或自立门户，是一个有力的信号。在最了解各家实验室技术方向和研究文化的人看来，Anthropic 已经成为首选目的地——不只因为 Claude 的商业成绩，也因为这里对 AI alignment 研究的重视程度。前沿人才的流向是行业走势最真实的指标之一，而今天 Karpathy 的加入，把这个信号说得非常清楚。

同日，Anthropic 宣布收购 Stainless。Stainless 是一家专门为 AI 公司自动生成和维护 SDK 库的工具型初创公司，OpenAI、Google、Cloudflare 都曾依赖它来维护各自的 API 客户端。SDK 是开发者接入任何一家 AI API 的入口：SDK 的质量决定首次集成的摩擦感和生产环境的稳定性。Anthropic 把这个入口收进来，意味着 Claude 的接入体验将由 Anthropic 自己掌控，而不是通过第三方工具。从公开信息合理推断，Stainless 往后为竞争对手维护 SDK 的可能性会大幅降低。这是生态层面的战略布局，不只是工具收购。

陪审团驳回了 Elon Musk 对 OpenAI 的全部诉讼，认定起诉已超过时效。Musk 最早在 2024 年起诉 Altman 和 OpenAI，核心主张是 OpenAI 背离了最初的非营利使命。此案的驳回直接扫清了 OpenAI IPO 的一个重要法律变量，投资方和监管机构现在可以更专注地审视上市本身的条件。

Meta 将内部 7000 名员工重组为四个 AI 专项部门，同时压平管理层级。四个部门分别聚焦于 AI 产品、基础设施、研究和商业化。Meta 今年资本支出规划高达 1350 亿美元，这次重组是配套的组织架构调整：管理层减少，直接产出预期更高。对 Meta 员工来说，这意味着有更少的中间层，也有更直接的绩效压力。

Unitree Robotics 已向上交所 STAR 板提交 IPO 申请。Unitree 是目前全球出货量最大的人形机器人公司，同时已经实现盈利并在增长。在这个赛道上，它的竞争对手包括 Figure（背后有 OpenAI 和 Bezos 的投资）、1X Technologies、Agility Robotics（亚马逊旗下）以及 Tesla Optimus。Unitree 的优势在于价格激进和量产能力，IPO 申请意味着资本市场对中国硬件公司的人形机器人商业化路径开始给予正式背书。

Google 与黑石（Blackstone）成立合资公司，计划在 2027 年前建成 500 兆瓦的 AI 算力产能。500 兆瓦大约相当于一座中等规模城市的用电量。这是新的大体量算力供应商入场，对 AWS 和 Azure 形成直接竞争，理论上会在未来几年压低算力定价。

Meta 在路易斯安那州农村建造一座 5 吉瓦的 AI 数据中心，预算超过 2000 亿美元。这是当前已知最大规模的单体 AI 基础设施项目之一。对路易斯安那而言，这在带来就业和税收的同时，也带来了电网和水资源的巨大压力，以及一个掌控了当地数十亿美元投资的单一企业主的政策谈判筹码。

今年全球大科技公司在 AI 基础设施上的资本支出合计将达到 7000 亿美元，而同一时期，基础模型正在快速商品化——API 价格在过去两年里每隔几个月就下降一次。支出飙升和价格下降同时发生，逻辑上只有一条路能走通：应用层需求必须增长到足够大，才能消化这轮建设出来的产能。如果杀手级应用没有及时出现，这笔钱就会变成行业历史上最贵的一次过剩投资。这是当前整个 AI 行业最核心的不确定性——不是技术能不能做到，而是需求是否会跟上。

公众和政界对 AI 基础设施项目的抵制在增加，反对方向包括数据中心的电网和水资源消耗、AI 对就业市场的冲击，以及对大型科技公司权力集中的担忧。这种阻力已经开始影响个别项目的选址和审批周期，是 AI 基础设施扩张计划里一个不断增长的系统性变量。

【新品速递】

Google 发布了 Gemini 3.5 Flash。这是一款小型前沿模型，核心定位是速度、行动能力和多模态推理的平衡。对开发者来说，它提供了一个在 API 成本和模型能力之间重新折中的选项：用不到最大模型全部能力的场景，现在有了更经济的替代。

同日，Google 还发布了 Gemini Omni，一款支持视频生成的多模态模型。生成式 AI 的边界从文字和图像延伸到视频，降低了视频内容大规模生产的入门门槛。

Google Search 正在发生结构性改变——搜索结果的排序方式、摘要呈现、内容分发逻辑都在悄悄变化。这不是界面层面的迭代，而是用户如何发现信息的底层机制在被重写。对内容创作者、SEO 行业和所有依赖搜索流量的网站来说，这是一个需要持续追踪的变量；它覆盖的规模是数十亿用户的日常信息入口。

Cursor 发布了 Composer 2.5，新版编程 agent 使用了强化学习和合成数据训练，能力有明显提升。Cursor 是目前用户基数最大的 AI 辅助代码编辑器之一，2.5 版本在与 GitHub Copilot、Windsurf 等对手的竞争中是一次实质性迭代。

xAI 为 Grok 推出了 Skills 功能：用户可以教 Grok 自定义函数，之后在所有对话里永久复用，不用每次重新描述。类比来说，这是给 AI 助手建立了一个持久的工具箱，而不是每次见面都从零开始介绍自己的工作方式。对重度用户和开发者来说，这减少了大量重复设置的摩擦。

NVIDIA 专门为 AI 加速器设计的主机处理器 Vera CPU 已经发货给 Anthropic 和 OpenAI 等顶级 AI 实验室。GPU 处理推理计算，但数据调度和协调层也需要专用优化——Vera 针对的就是这个环节。前沿实验室现在有了从上到下为 agent 工作负载定制的芯片组合。

Cloudflare 推出了 Mythos Preview，一款 AI 代码安全扫描工具，已在 50 多个代码仓库上完成大规模验证，结果被描述为显著进步。AI 辅助安全扫描从实验阶段向企业级可用迈出了实质性一步。

Amazon 卫星宽带服务 Leo（即 Amazon 对标 Starlink 的产品）的 Wi-Fi 路由器 FCC 申请图像已公开，支持 Wi-Fi 6、Mesh 组网、蓝牙 LE 和 Zigbee。Amazon 进入卫星宽带市场的硬件进展在具体化，与 SpaceX Starlink 的正面竞争进入倒计时。

Browse 是一个开源浏览器命令行工具，允许 AI agent 通过点击、滚动和表单填写直接自动化操作任何网站，过程在本地或远程 Chromium 里实时可见。传统 AI agent 只能通过 API 与系统交互；Browse 让 agent 覆盖那些没有 API 的遗留系统，大幅扩展了 agent 能自动化的操作边界。

Apple 为其设备集成了 AI 驱动的无障碍功能，包括 AI 图像描述、实时字幕和自适应交互界面。数百万残障用户直接在日常设备上获得了新能力，这也是 AI 落地规模最大、门槛最低的消费者场景之一。

【技术与洞察】

研究人员在 Qwen 大模型的权重里找到了实施政治审查的具体神经电路，并且能精准地将其关闭。这揭示了一个关键事实：审查机制不是在预训练数据里"炼"进去的，而是作为一层独立的控制结构，叠加在模型的事实知识之上。这把问题从"模型会不会拒绝"（黑盒行为问题）转变成了"关闭开关在哪里、谁能访问"（白盒架构问题）。对部署来说，这意味着模型的行为护栏不是固定承诺——它们是可编辑的权重，谁掌控权重，谁就掌控护栏。真正的 AI 安全可能需要控制机制本身的不可篡改性，而当前的模型权重并不提供这种保证。这是安全研究领域的一次范式转变。

大模型评估的方式正在从静态 benchmark 测试，转向真实 agent 在长时间跨度里的动态表现测试，尤其在编程和医疗等高风险领域。静态排行榜无法暴露 agent 在长任务链里的失败模式；而现在 AI 系统已经进入代码审查和医疗决策等关键场景，评估基础设施必须跟上实际部署的风险级别。这是 AI 测试领域安静进行的一场基础性革新。

语言模型在预训练过程中会不可预测地在两种学习模式之间跳变：记忆具体模式，或学习可泛化的规则。这种"模式跳变"是模型有限容量在记忆和泛化之间的竞争结果，当前的优化技术无法消除它。这对扩展定律有意义：如果模式跳变是训练的内生约束，它就限制了每个参数能压缩多少实际能力，未来对更大模型的预期需要把这个约束考虑进去。

KV 缓存——即大模型推理时用于存储注意力键值对的内存结构——正在成为推理优化的核心战场。当计算不再是瓶颈，内存移动效率就成了决定速度和成本的主因。整个推理栈（硬件、量化策略、批处理框架、服务系统）都将围绕 KV 缓存管理策略重新组织。对构建或选择推理基础设施的团队来说，这是接下来最值得跟进的架构方向。

注意力机制的压缩技术——包括 KV Sharing（键值共享）、多头压缩（MHC）和 Compressed Attention（压缩注意力）——正在降低模型推理的成本和内存需求。这些技术是让更小的模型在边缘设备上实际可用的架构基础；推理成本的下降，是应用层大规模落地的结构性前提。

Coinbase 部署了一套四层多 agent AI 系统，融合了传统机器学习和推理 agent，目前已能自主处理美国 55% 的欺诈案件。这不是实验室 benchmark 上的理论胜利，而是替换了一个时间敏感、人力密集的真实运营流程。55% 的自主率划出了当前的能力上限：剩余 45% 大概率是新型欺诈模式或需要策略判断的边缘案例。多 agent 推理现在已经不是新鲜概念，而是规模化合规运营里的基础能力配置。

Apple 把不合格或规格偏低的芯片，通过关闭部分功能或降频的方式，重新定向到低端产品线使用，而不是报废。这是芯片制造里的"分级处理"（binning）实践——其他芯片厂商会丢弃或低价外售的东西，Apple 路由进自己的产品矩阵，维持了跨产品线的毛利。入门款 iPhone 的价格之所以能压得住，供应链套利是不可忽视的一部分原因。

Simon Willison 发布了过去六个月 LLM 发展的综述，将 2025 年 11 月标记为编程 agent 开始真正实用的拐点——在那之后，用 AI 辅助写代码从新鲜感变成了实际工具。对持续追踪这个领域的人来说，这提供了一个有外部参照意义的时间节点。

【产品与人物】

AI 正在把产品经理（PM）角色分化成不同的原型。根据与 AI 工具的整合深度不同，PM 的实际工作方式已经出现了相当大的分叉：有人用 AI 加速决策，有人用 AI 替代以前依赖工程师完成的执行步骤，有人成为了 AI agent 工作流的编排者。"PM"这个职位标签下的实际职责正在出现结构性分化，这让跨团队的职能对齐变得更复杂，也对公司的组织设计和招聘标准提出了新要求。这是 AI 时代对产品团队运作方式最深层的一次重塑。

AI 工具让没有编程背景的 PM 也能自己原型化、上线、协调执行，而不再依赖工程师作为"翻译层"。这重新定义了 PM 的权责边界：从管理需求 backlog 和协调排期，转向直接拥有从想法到产品的完整执行链。PM 和工程师之间的分工边界在模糊，谁主导产品节奏的权力结构也在悄悄位移。

在 AI 时代，产品增长放缓的根本原因往往是产品迭代速度和竞争力不够，而不是销售能力不足。工程和产品团队现在直接承担增长责任；功能迭代速度已经成为竞争力本身的一部分，而不只是一个输入变量。

Stripe 前 CTO 的观点：PM 应该积极用 AI agent 自动化日常工作流，同时把精力转移到战略判断和品味把关上——成为 agent 的编排者，而不是任务执行者。这个框架的关键在于两个边界的认知：什么可以自动化，哪里必须保留人的判断。这是目前最有实操意义的 AI 时代 PM 能力框架之一。

AI 产品化的模式正在从独立的聊天功能，转向嵌入真实工作流的 agent。Notion 推出了 Notion Workers，Android 引入了 agentic 工具；同时，部分公司开始主动裁减弱 AI 功能，只保留真正解决具体工作环节的能力。AI 功能的生存门槛在提高：从"我们加了一个 AI 对话框"，到"AI 实际接管了一个完整的工作步骤"。

小公司可以通过清晰的差异化定位对抗 Google 这样的大型平台——识别平台服务不好的细分群体，在这个点上做到极致，而不是在全线上与大厂竞争。这是产品策略里的经典原则，但在 AI 时代，因为大模型让产品功能同质化的速度加快，清晰的定位反而变得更稀缺、更有价值。

Peter Neumann 离世，享高龄。Neumann 是计算机科学家，RISKS Digest 通讯的创办人。RISKS Digest 创办于 1985 年，几十年来持续记录技术系统的真实失效案例和系统性风险，是互联网上持续时间最长的专业技术通讯之一，影响了整整一代安全研究者和可靠性工程师的思维框架。他的离世是计算机科学史上一个值得记录的时刻。
