大家好,这里是又咋啦?!完整版。今天是2026年六月二十五日,为你带来今天所有值得关注的科技动态。

首先来看 AI / 大模型。

第一, ByteDance 发布了 Seedance 2.5,一个从文字描述直接生成三十秒四K视频的模型。对内容创作者和营销团队来说,这把AI视频生成的质量门槛又抬高了一截——不过 ByteDance 在美国市场的监管处境依然悬而未决。

第二, Mistral 发布了 OCR 4,一个跨一百七十种语言提取文档结构化数据的模型,在表格、表单和混排版式上达到当前最优水平。如果你的工作涉及合同、发票或研究文献的规模化处理,这个方案已经可以直接跟 Adobe 和 AWS 的文档 API 竞争——尤其是非英语文档,那是过去各大云厂商一直比较弱的地方。

第三, Krea 2 是 Krea AI 推出的新图片生成模型,核心卖点是可控性:不是"生成点惊艳的",而是"精确生成我设计好的那个"。它进入的市场已经很拥挤——Midjourney、Stability AI、Adobe Firefly 都在——但对需要稳定可预测输出、而不是随机惊喜的创意专业人士来说,这个定位有差异化价值。

第四, OpenAI 推出了 Bidi 1,ChatGPT 的新语音模型,支持真正的双向同时通话——边说边听,而不是过去那种对讲机式的你说我听。在架构层面,ChatGPT 的语音体验现在更接近真正的电话通话了。当然,架构改了不等于对话质量就跟上了,还得实际体验才算数。

第五, 一个研究团队发布了 VibeThinker,一个参数量只有三十亿的模型,在推理基准测试上达到了 Claude Opus 4.5 的水平。训练方法结合了监督微调和 GRPO——一种强化学习技术,通过奖励正确的推理链路来优化模型。三十亿参数是什么量级?小到可以在消费级笔记本 GPU 上跑;Opus 4.5 需要数据中心规模的硬件。这是最近一系列结果里又一个说明"训练方法比规模更重要"的案例。对于现在用前沿 API 按 token 付高价做推理任务的团队,值得认真关注。

接下来是 AI 产业 / 策略。

第一, "The Coming Loop"这篇文章在开发者社区广泛流传,论点值得认真对待。核心是:现在的 agent 循环——AI 自动决策、执行操作、再循环——已经快到开发者可以在完全不理解 agent 做了什么的情况下就把功能发布出去的程度。作者担心的不是 agent 失败,而是它成功了,但没人为它走过的推理路径负责。现有的软件可追责机制——代码审查、测试套件、变更记录——都是为人写的代码设计的,没有一种能捕捉 agent 在三十秒内经历的一万个子步骤到底做了什么决定。实际影响:如果你现在在生产环境部署 agent,"测试通过了"已经不是足够的治理标准。你的部署流水线需要记录 agent 的决策过程,不只是输出是否正确。没有这个基础设施的团队,迟早会以合规或法律责任的形式补上这一课。

第二, Cursor 的故事值得作为一个产品策略来理解,而不只是一个产品发布。Cursor fork 了 Microsoft 的开源编辑器 VS Code,把 AI 原生编辑作为核心重新构建——而不是插件。关键动作:保留了所有 VS Code 扩展的兼容性,开发者生态系统直接继承过来了。Microsoft 没法复制这个,因为它的商业模式依赖那个插件生态系统完整存在。这是教科书式的反向定位:你构建了竞争对手在结构上无法复制的产品,复制意味着损害自己的核心业务。对创业者来说,值得问的问题是:你进入的市场里,现有玩家的商业模式在哪个方向上限制了他们?那里就是反向定位的窗口。

第三, AI agent 市场正在呈现一个可预测的弧线:创业公司发布野心勃勃的全能 agent,靠新鲜感获得早期增长,然后在第五十个边界案例失败时迎来大规模流失。存活下来的产品是窄的——一个工作流、一类用户、一个定义清晰的成功条件。有明确升级路径的客服 agent 在跑;定位为"AI 员工"的通用 agent 一般三个月左右迎来流失高峰,因为每个组织特有的边界案例会把通用模型压垮。对创始人的直接启示:产品聚焦在这个市场不只是好的产品实践,它是首要的生存机制。宽泛的覆盖范围是融资材料里的特性,不是产品特性。

第四, 一篇流传颇广的投资分析文章认为,可持续竞争优势在 AI 时代变得越来越短命——任何护城河都比以前更快被竞争掉,花力气维护护城河等于把资源浪费在本该用于下一次移动的地方。对创始人和投资人可操作的版本:把竞争优势当作临时跑道,而不是永久结构,以迭代速度而不是防御性来优化。文章的论点是 AI 能力周期已经压缩了这个时间线——过去能持续几年的护城河,现在几个季度就被侵蚀了。

第五, 《艾尔登法环》的低技术 AI 这篇文章分析了 FromSoftware 如何用手工编码的逻辑——行为树和状态机——而不是学习型模型,实现出色的 NPC 行为。值得注意的元层面观点是:游戏里最受玩家喜爱的 AI 驱动体验,是由理解了约束条件、做出明确设计选择的设计师构建出来的,不是靠模型从数据里涌现的。对于追逐用 LLM 驱动游戏角色或复杂 agent 行为的团队,这是一个有价值的反向信号:有时候正确的工具就是一个有人类编辑的、设计精良的状态机。

第六, AI 推理服务商正在遭遇一个结构性定价困境:算力有成本下限,但竞争把价格压向这个下限,结果没有利润空间。投资人 Tom Tunguz 的分析认为,基于价值定价——对结果收费而不是对 token 收费——是唯一的出口,但这要求掌握应用层,不能只是模型层。纯粹卖推理算力的厂商是在一个无法靠利润赢的商品市场里竞争。对任何做 AI 推理业务的团队,核心问题是:你是在向应用表面方向构建,还是只在建管道?管道生意存在,就是没有回报。

第七, "Prompt Debt"是个新术语,描述的是真实问题:用自然语言指定系统行为,让规格说明本质上变得模糊,难以版本化。依赖 prompt 驱动架构的团队在积累技术债——不是代码层面的,是自然语言层面的:不同版本的模型对同一段 prompt 解释不一样;没法像单元测试那样测试 prompt;升级底层模型时会悄悄退化。实际影响:prompt 应该像代码一样被管理——版本化、测试覆盖、有明确负责人——而不是随意放在某个 dashboard 里的配置文字。

第八, 美国的 AI 出口管制——最初是为了阻止对手获取前沿 AI——现在把 NSA 自己对 Anthropic Mythos 工具的访问也切断了,而 NSA 此前一直在用这个工具做情报分析。这是出口管制附带伤害的一个具体案例:用来拦截对手的语言宽泛到连国内政府用户也拦下来了。这也揭示了法规起草上的漏洞:没有给持有安全许可的国内用户开豁免。NSA 本身没有公开证实这个用途——这是媒体报道的内容。

第九, Trump 政府正在推动 Meta 自愿提交其 AI 模型接受政府评估——从上届政府推强制标准的路线转向了。对 Meta 来说,自愿提交是策略性动作:展示配合姿态,但没有强制执行的风险,因为自愿项目没有惩罚机制。从更大的政策图景看,这代表了美国当前的 AI 治理思路:政府表示关切,企业展示合规,但不产生任何有约束力的规则。这是否会产生实质性治理,取决于评估过程背后有没有真正的标准。

接下来是 AI 产品 / 工具。

第一, Anthropic 推出了 Claude Tag,一个原生集成在 Slack 里的 AI 协作工具,团队成员可以直接在频道里 @ 它来分配任务。最关键的区别:Claude Tag 是多人共享的——整个团队可以在同一个 Claude 对话线程里互动,每个人都能看到彼此的问题和 Claude 的回应,上下文不会被孤立在某一个人手里。这是真正的 AI 原生工作流集成的形态:不是你一个人悄悄开一个私聊窗口,而是让 AI 成为共享频道里的一个参与者,所有人都可以指导、纠正、在它的基础上继续推进。直接竞争对手是 Microsoft Copilot for Teams 和 Google Duet in Workspace,但两者都是叠加在已有协作平台上的;Claude Tag 是为 Slack 本来的运作方式而构建的。对于已经把 Slack 当作工作操作系统的团队来说,上手门槛在结构上就很低。真正的问题是:分配任务给 Claude 会成为日常习惯,还是在任务足够难的时候就退回人来做?

第二, Polsia 是一家把 AI agent 作为核心运营模型的创业公司——不是用 AI 工具提升现有团队效率,而是用 AI agent 替代雇员,这是它的结构性商业决策。他们公布的数字是年度经常性收入一千万美元,员工不到五人。agent 负责销售推广、客服和内部运营;人负责战略和异常处理。这是目前能看到的,AI 原生公司在早期营收阶段最清晰的活体案例。需要关注的失败模式是脆弱性:agent 驱动的运营在边界案例触碰到覆盖盲区时,可以大规模、静默地失败,而五个人的团队监测和恢复的能力是有限的。这个模式能不能在更多客户和更多边界案例的规模下撑住,才是真正的测试。

第三, AWS 推出了 Lambda MicroVMs,为每个 Lambda 函数调用提供硬件级虚拟机隔离,而不是过去的容器级隔离。对运行不受信任代码的团队——AI agent 自动生成并执行代码、多租户沙箱环境——这是在同等价格点和 Lambda 亚秒冷启动特性下,有实质意义的安全升级。

第四, "Unlimited OCR"是一种新的文档解析技术,把整份文档作为长图像序列在单次模型推理中处理完,而不是分块再拼接。对处理大型合同、多章节报告或冗长监管文件的团队,这解决了分块解析的核心问题:跨块的上下文会丢失,重组时精度会下降。单次处理没有这个问题。

第五, IBM 发布了 CUGA——可配置通用 agent 框架——一个开源的 agent 搭建组件,处理规划、记忆、工具调用和执行循环,可以基于任何模型构建 AI agent。IBM 的战略逻辑是开发者生态:开源降低了在他们云和模型基础设施上构建的门槛。CUGA 对标的是 Anthropic、OpenAI 和 LangChain 的 agent 框架——开源对受监管行业尤其重要,因为这些行业往往无法使用封闭的专有基础设施。

第六, NVIDIA 发布了一套 agent 构建工具,专注于使用开放权重模型构建可定制的企业级 AI agent,企业可以审计、微调并部署在自己的基础设施上。NVIDIA 的定位是对标黑盒 API agent:论点是金融、医疗、国防等受监管行业,需要能检查和控制的模型,而不是只能观察输出的 API。

第七, 包括 Anthropic 和 OpenAI 在内的多家 AI 服务商,在过去二十四小时内同时出现了错误率上升。同时性表明这是上游共享基础设施的问题——可能是 DNS、CDN 或某个共用的云基础设施层。如果你的应用为了冗余而分散调用多家 AI 服务商,这是一个提醒:如果这些服务商在更上游共享基础设施,多供应商策略也可能无法防止同时失效。

接下来是 AI 与社会。

第一, "战争的另一种方式"这篇文章的论点是:自主武器——无人机、机器人弹药、无人地面车辆——正在通过降低投送方的人员代价来重塑军事力量的结构。历史上,约束军事升级的政治机制主要是伤亡数字——民众会因为己方士兵的牺牲而对战争失去支持。自主系统打破了这个约束。作者的论点是这不是未来的事:乌克兰、加沙以及多个代理冲突现在已经在用可以大批量廉价生产、可以消耗使用的自主系统作战了。战略层面的反直觉推论是:更便宜、人员代价更低的武器不会让冲突变得不太可能,它们会降低启动一场冲突的政治门槛。对于跟踪国防科技投资浪潮——Anduril、Shield AI、Palantir 不断扩大的国防合同——的人来说,文章的核心论点是:这不是一个小众采购方向,它正在成为所有有能力使用的军队的主要采购方向。(以上反映的是作者的分析和关于已部署系统的公开报道;具体自主系统导致的伤亡数字存在争议。)

第二, 网络年龄验证法——在美国多个州和英国《在线安全法》框架下推进——公开定位为儿童保护措施。Cory Doctorow 的文章指出:核实某个用户不是未成年人所需要的机制,在结构上就是核实所有人身份的机制——你无法在不知道用户是谁的情况下判断他是否成年。具体结果是:商业年龄验证服务商——不是政府——最终持有了一份数据库,记录哪个成年人在哪个网站完成了身份核验。区域对比:EU 的数字服务法采取的是更谨慎的路线,要求适龄设计而非身份核验。对处于美国受影响州和英国的用户,实际影响是:使用任何受法律覆盖的网站,现在会在此前不存在的地方产生一条私营企业的身份记录。反直觉之处在于:这部法律被包装成限制对儿童的数据收集,但它的实现机制是对成年人创建新的数据收集。

第三, 麦迪逊广场花园对公开反对该场馆使用面部识别的活动人士建立了监控档案——记录他们的活动、关系网络和出席场合。这是面部识别被用作报复工具而非中立安保手段的具体案例:MSG 不只是用这个系统来拒绝被禁人员入场,而是用它主动追踪和侧写批评者。对于认为私营场馆的面部识别是被动安保手段的人来说,这是一个有据可查的反例。

接下来是 行业动态。

第一, Meta 正在构建 Arena,一个社交预测市场应用,用户可以对各类事件——选举、体育结果、市场走势——做出预测,准确率在自己的社交网络里公开可见。背景:预测市场最近随着 Polymarket 和 Kalshi 重新受到关注,两者都是匿名交易平台。Meta 的区别在于社交层:你的预测对你的人际网络公开,这把产品从金融投机变成了社交信号。最终它是一个独立的有意义产品,还是被折叠进 Facebook 动态里的一个功能,是关键的开放问题。

第二, SpaceX 测试了 Starfall,一个碟形货运舱,设计用于快速点对点货物投送——把最初的"地球到地球"火箭旅行概念应用到货物上,而不是乘客。Starfall 可以在一小时内把一批货物送到地球上任何地点。商业规模的经济性目前还没有验证;有意义的门槛是它能否在极度紧急的货物运输场景下与航空货运竞争——那些每磅成本不是主要考量、时间才是的场景。军事前沿部署的后勤保障是最明显的第一批客户。

第三, Swift Package Index——Swift 开发者的社区包注册库,类似 JavaScript 的 npm 或 Python 的 PyPI——正式并入了 Apple 的基础设施。对 Swift 开发者来说,这意味着社区包注册库现在由 Apple 官方维护,可靠性和长期支持有了保障。代价是中心化:包发现和治理流程从社区控制转向了 Apple 控制。这个模式跟 Apple 过去在 iOS 和 macOS 生态达到临界规模后吸收社区工具的模式是一致的。
